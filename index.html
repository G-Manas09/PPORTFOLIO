I’m a Computer Science graduate drawn to the practical side of cybersecurity: understanding how systems work, where they become exposed, and how defenders can spot meaningful signals.

I enjoy working across Linux, networking, web application security, and defensive monitoring. My projects reflect that range—from exploring Active Directory event visibility to building a web vulnerability scanner and designing more engaging ways to learn security.

My current direction is toward Security Operations, threat detection, and incident response, with a growing interest in how automation and AI can support security teams. I value hands-on practice, clear documentation, and being honest about what has been tested versus what is still being designed.
